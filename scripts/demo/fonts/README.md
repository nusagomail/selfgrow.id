# Huruf untuk infografis demo

Dipakai hanya saat merender infografis ebook demo menjadi PNG (`render-figures.mjs`), tidak
dikirim ke aplikasi.

- `caveat-latin-700-normal.woff2`: Caveat (tulisan tangan), SIL Open Font License 1.1.
- `dm-serif-display-latin-400-normal.woff2`: DM Serif Display, SIL Open Font License 1.1.

Sumber: paket @fontsource/caveat dan @fontsource/dm-serif-display.
- `jetbrains-mono-latin-500-normal.woff2`: JetBrains Mono (huruf mesin ketik untuk nota), SIL Open Font License 1.1. Sumber: @fontsource/jetbrains-mono.
